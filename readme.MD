# Create Logistics

Create Logistics is an addon for the Minecraft mod Create focused on advanced wireless logistics, contraption automation and vehicle control systems.

The project aims to extend the automation possibilities of Create and Create Aeronautics by introducing new blocks, controllers and logistics mechanics designed for moving contraptions and wireless infrastructure.

## Current Features

* Redstone Toggle Link

    * Wireless toggle receiver based on Create frequencies
    * Persistent ON/OFF state
    * Compatible with Linked Controller
    * Supports filtered and non-filtered wireless signals

## Planned Features

* Logistic Controller
* Contraption inventory interfaces
* Physics contraption storage access
* Vehicle logistics systems
* Wireless transport automation
* Advanced Aeronautics integration

## Dependencies

* Minecraft 1.21.1
* NeoForge
* Create
* Create Aeronautics

## Development Status

The mod is currently in active development and APIs/mechanics may change frequently.
